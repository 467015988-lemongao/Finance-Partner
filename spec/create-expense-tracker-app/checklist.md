# Checklist

## 后端
- [x] `expense-tracker-server/` 目录已创建，未修改仓库中任何现有项目文件
- [x] 首次启动时 `data/categories.json` 自动生成 7 个默认类目，且每个类目含 id/name/icon/color/isDefault/createdAt
- [x] 数据写入使用临时文件 + rename，且写入串行化，不产生损坏 JSON
- [x] `GET/POST/PUT/DELETE /api/categories` 全部可用，响应符合 `{ ok, data }` / `{ ok, error }` 格式
- [x] 新增类目时空名称、重名均返回 400 并给出中文错误说明
- [x] 删除被引用类目返回 409 且包含引用笔数；删除最后一个类目被拒绝
- [x] `GET /api/records` 支持 month/from/to/categoryId/keyword 组合过滤，返回按日期倒序
- [x] 新增账目时金额 ≤0、超过两位小数、类目不存在、日期格式非法、备注超 50 字均返回 400
- [x] `PUT /api/records/:id`、`DELETE /api/records/:id` 对不存在 id 返回 404
- [x] `/api/stats/summary` 返回总支出、笔数、日均、上月总额与环比，金额按分计算无浮点误差
- [x] `/api/stats/by-category` 返回类目金额与占比，按金额降序
- [x] `/api/stats/daily` 返回所选月份每一天的支出，无记录日期补 0
- [x] `/api/stats/monthly` 返回最近 6 个月（含所选月份）的总支出
- [x] 后端默认监听 3010 端口（支持 `PORT` 覆盖）且开启 CORS；本机 3001 被旧 `newyear-2027-server` 占用，已改用 3010 并完成联调验证
